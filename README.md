# AWS Cloud Assignments

Hands-on AWS projects focused on solidifying my cloud foundations. This repo builds a full custom network from scratch to master the fundamentals of cloud networking, routing and segmentation.

## Progress

| # | Assignment | What I built | Status |
|---|-----------|--------------|--------|
| 1 | [VPC & Networking](./assignment-01-vpc-networking) | Custom VPC with one public and one private subnet, correct routing for internet access, and EC2 instances deployed across both | ✅ Complete |
| 2 | [Application Load Balancer](./assignment-02-application-load-balancer) | Two web servers behind an ALB, plus a custom domain with HTTPS, Cloudflare-only access and an Auto Scaling Group | ✅ Complete |
| 3 | [S3 + CloudFront Static Site](./assignment-03-s3-cloudfront-static-site) | Static website on S3 served through CloudFront with HTTPS and a Route 53 alias on a delegated subdomain (bonus) | ✅ Complete |

## Skills demonstrated

VPC design, routing, NAT, security groups, EC2, load balancing, HTTPS/ACM, Cloudflare DNS, Auto Scaling, S3 hosting, CloudFront CDN, caching and invalidation, Route 53 DNS
